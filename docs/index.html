academic-job-platform

A Serbia-first academic job listing aggregator (with international expansion), plus a thesis formatting/similarity-estimate module. Source, docs, and the full real-code history live on GitHub.

Python / FastAPINext.js Postgreslocalhost-only

What this is

A set of connectors crawl academic job boards and institutional career pages (starting with Serbian universities/institutes, extended to a handful of international aggregators), reconcile them against OpenAlex's own institution data, de-duplicate across sources, and serve the result through a read-only API and a Next.js UI with filters, a map view, and English/Serbian (Latin + Cyrillic) locales. A separate module lets a student upload a thesis for structural/formatting checks and a transparent, documented similarity estimate against a handful of real external sources.

Honest scope - what this deliberately is NOT

  • Not a public, hosted service. This is a localhost-only research/portfolio project. There is no publicly reachable live instance - running it means cloning the repo and starting it on your own machine (see the README).
  • The similarity estimate is not Turnitin (or any commercial plagiarism-detection service) - it is a documented, transparent heuristic over a small, named set of real sources (internal corpus, OpenAlex, Crossref, Semantic Scholar, Unpaywall, and - only with the student's own opted-in credentials - Copyleaks), never presented as a "plagiarism %" or an authoritative verdict.
  • Blocked or robots-disallowed sources stay deeplink-only. A source this project cannot legitimately crawl (TLS failures, a disallow rule, a known soft-404 host) is never scraped anyway - it is linked out to directly, honestly, with the reason recorded.
  • No OCR. A scanned PDF with no extractable text is flagged as such, honestly, not silently skipped or fabricated.

Architecture (one line each)

connectors (one per source family, robots-checked, rate-limited, TLS-verified) → rawstore (content-addressed raw HTTP envelopes - every field traces back to a real fetched byte string) → ingest (cross-source dedupe) → Postgres → a read-only FastAPI API → the Next.js UI (HTTP only, no direct DB access). A separate applicants module matches an uploaded CV against open listings with a documented, weighted, fully-explained scoring formula - never a black-box number.
